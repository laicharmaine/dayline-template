First-time setup

Dayline creates its Notion databases for you. About 2 minutes.

1 Your Notion integration token

✓ Using the NOTION_TOKEN you set in Vercel.

Paste the “Internal integration secret” from notion.so/profile/integrations. It is only used for this setup and is not saved by Dayline. (You still need to add it to Vercel as NOTION_TOKEN.)

2 Pick the page to hold your Dayline databases

In Notion, open the page, click ••• (top right) › Connections and add your integration first. Then:

    …or paste the page link:

    3 Create the databases

    Creates: To Do, Recruiting pipeline, Brainstorm, People, Touch points and App data (all named “Dayline · …”). Safe to click again: anything already made under that page is reused.

    4 Paste these into Vercel, then redeploy

    Vercel › your project › Settings › Environment Variables. Add each line (name = left of “=”, value = right). Then Deployments › latest › ••• › Redeploy.
